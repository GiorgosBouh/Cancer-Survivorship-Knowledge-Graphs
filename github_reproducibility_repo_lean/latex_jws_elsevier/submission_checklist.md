# Submission Checklist Draft

## Completed in this LaTeX package

- Elsevier `elsarticle` double-column manuscript draft.
- Abstract under 250 words.
- 7 keywords.
- 5 highlights in a separate editable file.
- Numbered references via `elsarticle-num`.
- Acknowledgements section before references.
- Funding, competing interest, ethics, data availability, CRediT, and generative-AI declaration sections.
- Claim boundaries for MIMS, MVPA, sedentary classification, and self-reported cancer history.
- NCIt expert-review status updated to completed with qualified assertions.

## Still required before submission

- Final author names, order, affiliations, and corresponding-author email.
- Repository/archive DOI for code and generated reusable artifacts.
- Completion or explicit limitation of external domain/ontology review.
- Confirm all co-author declarations and CRediT roles.
- Final Scopus verification of every bibliography entry.
- Compile PDF and check double-column table widths.
- Add any final supplementary material files required by JWS/Elsevier.
